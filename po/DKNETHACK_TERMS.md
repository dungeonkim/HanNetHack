# dknethack 용어 합의

이 브랜치(dknethack)에서 정한 번역 용어. 목표는 넷핵을 처음 하는 사람이 바로 알아듣는 말.
`po/ko_manual.po`, `dat/locale/ko/*`, ffstation 쪽 UI(`games/dknethack/src`)가 모두 이 표를 따른다.

## 능력치
힘 · 솜씨 · 건강 · 지능 · 지혜 · 매력 (약칭 없음)

- 솜씨(Dex): 넷핵의 Dex는 손재주(명중, 여러 발 쏘기, 자물쇠, 함정)라서 민첩이 아니다.
- 건강(Con): 체력은 HP 전용. 반대말은 허약.

## 아이템 상태
| 원문 | 번역 |
|---|---|
| blessed / cursed | 축복받은 / 저주받은 |
| uncursed(알려짐) | 표시 안 함 |
| B/U/C 모름 | 미감정 |
| 종류 모름 | 정체불명의 |
| 강화 수치 모름 | +? |
| identify | 감정 |
| holy / unholy water | 성수 / 저주받은 물 |
| rustproof, fireproof, corrodeproof, rotproof, fixed | 녹 방지, 불 방지, 부식 방지, 부패 방지, 손상 방지 |
| partly eaten / partly used | 조금 먹은 / 조금 사용된 |
| unpaid / for sale / no charge | 계산 전 / 판매 중 / 무료 |

## 장비
이름표는 모두 **(장착)**. 예외만 구분한다.

| 상황 | 이름표 |
|---|---|
| 입은 갑옷, 든 무기, 낀 반지·부적 | (장착) |
| 입는 중 / 벗는 중 | (장착 중) / (해제 중) |
| 쌍수 전투 | (오른손 장착) / (왼손 장착) |
| x로 바꿔 드는 무기 | (보조 무기) |
| 화살통 | (화살통에 장비) / (주머니에 장비) / (투척 준비됨) |

문장으로 된 메시지는 자연스러운 동사를 쓴다(예: 손에 달라붙었다).

## 행동
| 명령 | 번역 |
|---|---|
| w / w- | 무기 들기 / 무기 넣기 |
| W / T | 갑옷 입기 / 갑옷 벗기 |
| P / R | 장신구 착용 / 장신구 벗기 |
| x | 보조 무기로 바꾸기 |
| Q | 화살통에 장비 |
| f / t | 원거리 공격 (화살통에 장비한 것을 쏘거나 던짐) / 던지기 |
| d / D | 버리기 / 여러 개 버리기 (제단에 올려 저주를 확인할 때도 같은 명령) |
| z | 마법봉 사용 (wand = 마법봉, staff = 지팡이는 육척봉 쪽) |
| #loot | 전리품 뒤지기 |
| s | 주변 탐색 |
| #force | 자물쇠 부수기 |
| ^D | 발로 차기 |
| #tip | 내용물을 모두 버리기 |
| #pray / #offer / #chat | 기도하기 / 제물 바치기 / 말 걸기 |
| #jump / #ride / #untrap | 점프하기 / 타기/내리기 / 함정 해체 시도 |
| #pay / #monster | 지불하기 / 몬스터의 능력 사용 |
| #enhance / Z | 숙련도 올리기 / 주문 외우기 |
| E | 바닥에 글쓰기 |
| : / , | 발밑 보기 / 줍기 |
| ^X / * | 내 상태 확인 / 장착 장비 확인 |
| \ / #overview / #chronicle / #conduct | 발견 목록 / 던전 정보 보기 / 모험 일지 / 도전 과제 |
| #adjust / #twoweapon | 소지품 단축키 변경 / 쌍수 전투 |

## 이름과 메모
- name(물건 하나, 몬스터): **이름 붙이기** → `"롱기누스"라는 이름의 창`
- call(물건 종류), #annotate(층): **메모해두기** → `물약 (메모: 치료?)`

## 물건 종류
| 원문 | 번역 |
|---|---|
| scroll | 스크롤 |
| spellbook | 마법책 |
| wand | 마법봉 |
