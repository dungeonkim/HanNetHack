# dknethack 용어 합의

이 브랜치(dknethack)에서 정한 번역 용어. 목표는 넷핵을 처음 하는 사람이 바로 알아듣는 말.
`po/ko_manual.po`, `dat/locale/ko/*`, ffstation 쪽 UI(`games/dknethack/src`)가 모두 이 표를 따른다.

## 능력치
힘 · 솜씨 · 건강 · 지능 · 지혜 · 매력 (약칭 없음)

- 솜씨(Dex): 넷핵의 Dex는 손재주(명중, 여러 발 쏘기, 자물쇠, 함정)라서 민첩이 아니다.
- 건강(Con): 체력은 HP 전용. 반대말은 허약.

## 아이템 상태
| 원문 | 번역 |
|---|---|
| blessed / cursed | 축복받은 / 저주받은 |
| uncursed(알려짐) | 표시 안 함 |
| B/U/C 모름 | 미감정 |
| 종류 모름 | 정체불명의 |
| 강화 수치 모름 | +? |
| identify | 감정 |
| holy / unholy water | 성수 / 저주받은 물 |
| rustproof, fireproof, corrodeproof, rotproof, fixed | 녹 방지, 불 방지, 부식 방지, 부패 방지, 손상 방지 |
| partly eaten / partly used | 조금 먹은 / 조금 사용된 |
| unpaid / for sale / no charge | 계산 전 / 판매 중 / 무료 |

## 장비
이름표는 모두 **(장착중)**. 예외만 구분한다.

| 상황 | 이름표 |
|---|---|
| 입은 갑옷, 든 무기, 낀 반지·목걸이 | (장착중) |
| 입는 중 / 벗는 중 | (장착하는 중) / (해제하는 중) |
| 쌍수 전투 | (오른손 장착중) / (왼손 장착중) |
| x로 바꿔 드는 무기 | (보조 무기) |
| 화살통 | (화살통에 장비) / (주머니에 장비) / (투척 준비됨) |

문장으로 된 메시지는 자연스러운 동사를 쓴다(예: 손에 달라붙었다).

## 이름과 메모
- name(물건 하나, 몬스터): **이름 붙이기** → `"롱기누스"라는 이름의 창`, `길들인 작은 개 하치`
- call(물건 종류), #annotate(층): **메모해두기** → `물약 (메모: 치료?)`

## 물건 종류
| 원문 | 번역 |
|---|---|
| scroll | 스크롤 |
| spellbook | 마법책 |
| wand | 마법봉 |
| amulet | 목걸이 (Amulet of Yendor = 옌더의 목걸이) |

## 기타
- item은 **물건** (아이템·물품 쓰지 않음)
- 방향은 나침반: 북·남·동·서, 북동·북서·남동·남서 (위/아래는 계단과 헷갈림)
- ^P: 지나간 메시지 보기, s 20회: 20턴 동안 탐색하기, 쌍수 전투 시작하기/그만두기

## 물건 이름
소지품과 발견 목록이 같은 이름을 쓴다: po의 msgctxt "objname" (영문 전체 이름이 키, objnam.c ko_objname). 의는 이름마다 귀로 정한다(혼란의 물약, 환각 물약).
- skill은 **스킬** (기술·숙련도 쓰지 않음). 단계: 미숙련 · 기초 · 숙련 · 전문가 · 스승 · 대종사. 올릴 수 있는 스킬은 노란 [숙련 가능]
- 메뉴 색 태그: `<#rrggbb>글자</>` (dknethack menu.js), 열 구분은 탭
