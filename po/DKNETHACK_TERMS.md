# dknethack 용어 합의

이 브랜치(dknethack)에서 정한 번역 용어. 목표는 넷핵을 처음 하는 사람이 바로 알아듣는 말.
`po/ko_manual.po`, `dat/locale/ko/*`, ffstation 쪽 UI(`games/dknethack/src`)가 모두 이 표를 따른다.

## 능력치
힘 · 솜씨 · 건강 · 지능 · 지혜 · 매력 (약칭 없음)

- 솜씨(Dex): 넷핵의 Dex는 손재주(명중, 여러 발 쏘기, 자물쇠, 함정)라서 민첩이 아니다.
- 건강(Con): 체력은 HP 전용. 반대말은 허약.

## 장비
이름표는 모두 **(장착중)**. 예외만 구분한다.

| 상황 | 이름표 |
|---|---|
| 입은 갑옷, 든 무기, 낀 반지·목걸이 | (장착중) |
| 입는 중 / 벗는 중 | (장착하는 중) / (해제하는 중) |
| 쌍수 전투 | (오른손 장착중) / (왼손 장착중) |
| x로 바꿔 드는 무기 | (보조 무기) |
| Q로 고른 것 (quiver) | (원거리 공격용) — 화살·돌·단검 모두 같음. "화살통"이라는 말은 쓰지 않는다 |

문장으로 된 메시지는 자연스러운 동사를 쓴다(예: 손에 달라붙었다).

방패는 입지 않고 **손에 든다**(한국어일 때만, iactions.c·do_wear.c):
물건 메뉴 W = 손에 들기, w = 무기로 사용하기, T = 손에서 내려놓기, 교체 = "<방패>를 내려놓고 들기";
메시지는 msgctxt "shield" — "이제 X를 들고 있다." / "X를 손에서 내려놓았다."

## 이름과 메모
- name(물건 하나, 몬스터): **이름 붙이기** → `"롱기누스"라는 이름의 창`, `길들인 작은 개 하치`
- call(물건 종류), #annotate(층): **메모해두기** → `물약 (메모: 치료?)`

## 물건 종류
| 원문 | 번역 |
|---|---|
| scroll | 스크롤 |
| spellbook | 마법책 |
| wand | 마법봉 |
| amulet | 목걸이 (Amulet of Yendor = 옌더의 목걸이) |

## 기타
- item은 **물건** (아이템·물품 쓰지 않음)
- 방향은 나침반: 북·남·동·서, 북동·북서·남동·남서 (위/아래는 계단과 헷갈림)
- ^P: 지나간 메시지 보기, s 20회: 20턴 동안 탐색하기, 쌍수 전투 시작하기/그만두기

## 물건 이름
소지품과 발견 목록이 같은 이름을 쓴다: po의 msgctxt "objname" (영문 전체 이름이 키, objnam.c ko_objname). 의는 이름마다 귀로 정한다(혼란의 물약, 환각 물약).
- skill은 **스킬** (기술·숙련도 쓰지 않음). 단계: 미숙련 · 기초 · 숙련 · 전문가 · 달인 · 대가. 무기 스킬 이름은 물건 이름과 따로 정할 수 있음(msgctxt skill: 숏소드, 곡도, 폴암). quarterstaff는 물건·스킬 모두 스태프, trident는 삼지창. 올릴 수 있는 스킬은 노란 [숙련 가능]
- 메뉴 색 태그: `<#rrggbb>글자</>` (dknethack menu.js), 열 구분은 탭
- 몬스터를 죽이면 **처치했다** (죽였다 쓰지 않음)
- 주문 분류: 공격 · 치료 · 탐지 · 상태이상 · 성직 · 이동 · 물질조종 (스킬 창은 "~ 주문", 주문 목록 열은 이름만; msgctxt skill / spell_school)
- **숙련자용 메뉴**: 초보에게 필요 없는 선택지는 dknethack 설정 "숙련자용 메뉴 추가"(기본 끔, pickup.c dknh_expert_menus)가 켜졌을 때만 보인다. 예: 상자의 꺼내고 넣기 (1턴) / 넣고 꺼내기 (1턴)
- **주문 이름**은 마법책 이름에서 "마법책"을 뺀 것과 같다(굴착 마법책 → 굴착). 일반 단어 번역과 겹치면 msgctxt "spell"로 따로 둔다(tr_spell_name, obj_descr_i18n.c의 C_("spell", ...)).

## 몬스터 이름
- were-X는 **X인간**: 늑대인간, 자칼인간, 쥐인간.
- 같은 이름을 두 몬스터가 쓰지 않는다: elven monarch 엘프 통치자, guard 경비병 / watchman 감시자, high priest(ess) 고위 사제 / Arch Priest 대사제.
- lord / lady는 둘 다 **귀족** (드워프·코볼트·노움·오거·뱀파이어·엘프). 성별 없는 형태(leader)는 지도자.
- displacer beast는 환영수 (허상 때문에 공격이 빗나감), aligned cleric은 신전 사제 (제단을 지키는 사제).
- newt는 도롱뇽 (작고 약한 첫 몬스터; lizard 도마뱀과 구분).
- 붙여 쓰는 굳은 말은 붙인다: 살인벌, 여왕벌. 설명이 필요한 짧은 원어는 풀어 쓴다: 게코도마뱀, 비명 버섯(F 곰팡이류).

## 직업과 칭호
- **"여"를 붙이지 않는다**: 남녀 이름이 따로 있어도 한국어는 하나(사제, 귀족, 영주, 대주교, 영웅, 군주…). 성별 자체가 뜻인 말만 예외(여왕, 여신, 쿠노이치).
- 직업 이름과 그 직업의 몬스터 이름은 같다: 원시인(caveman·cavewoman·cave dweller), 레인저, 사제.
- 한 직업 안에서 칭호가 겹치지 않게 하고, 낮은 칭호에서 높은 칭호로 올라가는 느낌을 준다(견습 마법사 → … → 대마법사).
- 원문이 다른 문자열과 같은 칭호는 msgctxt "rank"(botl.c tr_rank): Master 대사범(스킬 단계 달인과 구분), Dame 영주(옥좌 호칭과 구분).
- 백과사전(data.base)의 "<직업> 계급" 표는 게임 칭호와 같아야 한다.
- 사무라이 칭호는 원작 음차 그대로: 하타모토 → 로닌 → 닌자/쿠노이치 → 조슈 → 료슈 → 고쿠슈 → 다이묘 → 쿠게 → 쇼군 (첫소리 ㄱ, 외래어 표기법).
- 돈은 **골드** (금화·조크미드 쓰지 않음). 숫자에 붙여 "1542골드"; 상태줄만 "골드:1542". 상점 표시 "(450골드에 판매 중)", "(계산 전, 450골드)".
- 개수는 이름 뒤, 괄호 표시 앞: `부싯돌 x27 (원거리 공격용)` (menu.js itemName).
- 회색 돌 종류는 이름에 이미 돌이 있어 " stone"을 붙이지 않는다(부싯돌, 시금석, 행운의 돌).
- **종류 고르기 창**(꺼내기·넣기·여러 개 버리기, pickup.c query_category): 숙련자용 메뉴가 꺼져 있으면 건너뛰고 모든 종류로 바로 물건 목록.
  켜져 있으면 제목 "꺼낼/넣을/버릴 물건의 종류는?", 모든 종류 기본 선택, 맨 아래 "묻지 않고 전부 꺼내기/넣기/버리기" (msgctxt take_out·put_in·drop).
- role은 **직업** (역할 쓰지 않음): 직업 선택, <직업> <종족> <성별> <성향>, 확인창 "원시인 dd, 질서 성향의 인간 남성"

## 짐·신앙심·종료 창
- **짐 단계**(상태줄 botl enc_stat / 능력치 창 insight.c): 짐 많음 · 짐 무거움 · 짐 버거움 · 짐 한계 · 짐 초과.
  능력치 창은 한 문장: "짐이 많아서 이동이 다소 느려짐" → "…무거워서 …꽤" → "…버거워서 …매우" → "짐이 한계에 달해 이동이 극도로 느려짐" → "짐이 너무 무거워 움직일 수 없음".
- **신앙심**(alignment record, piously…transgressed): "당신은 신앙심이 매우 깊다 / 깊다 / 꽤 깊다 / 있다", 기준점 "성향에 충실하다",
  그 아래 "성향을 겨우 지키고 있다 / 이름만 지키고 있다", 음수 "성향에서 벗어났다 / 신에게 죄를 지었다 / 신에게 큰 죄를 지었다".
- **bones level**은 "다른 모험가가 죽은 층" (뼈 레벨 쓰지 않음).
- 플레이 시간은 "총 플레이 시간은 4분 39초였다" ("경과", "그리고" 쓰지 않음; 조사 {이었/였}).
- 창 색(ffstation menu.js): 창 제목 = ATR_BOLD (메뉴 질문과 같은 파란색), 카테고리·섹션 제목 = 그 밖의 attr (녹색), 게임 종료 공개 창도 같음.
  열을 맞출 값은 탭으로 나눈다: 능력치 "힘\t14 (한계 18)" (msgctxt characteristic), 처치한 몬스터 "고블린\t3".
- corpse는 **사체** (시체 쓰지 않음): 고블린 사체, 사체를 먹었다.
- 배고픔(능력치 창): "당신은 배가 부르다 / 배고프지 않다 / 배가 고프다 / 굶주려 쇠약하다 / 굶주려 쓰러질 것 같다". 상태줄은 짧은 "포만" 그대로.
- 캐릭터 선택에서 앞선 선택 때문에 고를 수 없는 항목: 회색 "종족 선택 불가" / "성별 선택 불가" / "성향 선택 불가".
